# Django Introduction

This section covers the basic introduction to Django before starting actual Django development.

The goal of this topic is to understand **what Django is, why it is used, what it provides, and where it fits in web development**.

---

## What is Django?

**Django is a high-level web framework written in Python.**

It is used to build web applications quickly and in a structured way. Django provides many features that are commonly required in web development, so developers do not need to create everything from scratch.

In simple words:

> Django provides a ready-made structure and tools that help Python developers build web applications.

Django is mainly used for **backend/server-side web development**.
